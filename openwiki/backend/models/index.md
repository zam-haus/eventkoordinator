# Backend Models Documentation

This directory contains backend model definitions.

## Contents

- **overview**: Overview of all backend models
- **udmtype**: UserDefinedModelType
- **config**: Configuration models
- **node**: Entity and field models
- **workflow**: Workflow definition models
- **policy**: Policy models
- **rules**: Validation rule models
- **migration**: Migration models
- **mailtemplates**: Mail templates for email notifications
